# 📊 Інтерактивний аналітичний дешборд: Клієнти, Запити, Послуги

Інтерактивний вебдешборд в одному HTML-файлі (`analytics_dashboard.html`) для візуалізації, фільтрації та перехресної звірки даних супроводу клієнтів, звернень (запитів) та наданих послуг.

Усі обчислення виконуються **повністю локально у браузері користувача** без передачі конфіденційних даних на сторонні сервери.

---

## ✨ Основні можливості

- **Завантаження даних двома способами:**
  - Локальні файли Excel (`.xlsx`, `.xls`) та `.csv` (через кнопку завантаження або перетягування Drag & Drop у вікно браузера).
  - Пряме підключення **Google Таблиць** за посиланням (URL).
- **Автоматична перевірка структури файлу:** при завантаженні система перевіряє наявність вкладок (`Клієнти`, `Запити`, `Послуги`) та необхідних колонок, виводячи детальне сповіщення у разі розбіжностей.
- **Глобальні фільтри та розумна обробка мультизначень:**
  - Фільтр **«Відповідальний менеджер»**: коректно розбиває клітинки з кількома менеджерами (через `;`, `,` або перенос рядка) для індивідуального підрахунку по кожному фахівцю.
  - Фільтр **«Дата аналізу»**: динамічно перераховує розподіл клієнтів на «Старий» / «Новий» та інтервали відсутності оновлень (`<Updated At>`).
  - Розбиття мультизначень у категоріальних полях (наприклад, *«Канал першого звернення»*, *«Що цікавить на момент першого звернення»*, *«Етап супроводу»* тощо).
- **Повна інтерактивність (Cross-filtering):**
  - Клік по будь-якому стовпцю, сегменту кругової діаграми або елементу легенди миттєво фільтрує скрол-таблицю записів знизу.
  - Клік по рядку таблиці відкриває повну картку запису з усіма полями.
  - Підтримка швидкого пошуку по таблиці, пагінації, експорту відфільтрованих даних у **CSV** та перемикання **світлої / темної теми**.

## 📈 Структура аналітики (28 показників і діаграм)

### 1. Вкладка «Клієнти» (1–16)
* **#1–3 KPI-картки:** Загальна кількість клієнтів, Загальна кількість запитів, Загальна кількість консультацій (кількість записів у вкладці «Послуги»).
* **#4:** Клієнти по менеджерах з розбивкою **Старий / Новий** відносно обраної *Дати аналізу*.
* **#5:** Клієнти по менеджерах з розбивкою за **Етапом супроводу**.
* **#6:** Клієнти по менеджерах з розбивкою **На якому етапі завершено**.
* **#7–8:** Кругові діаграми: *Військовий статус на початок супроводу* та *Статус клієнта на початок консультування*.
* **#9–13:** Розподіл клієнтів за *Віком*, *Каналом першого звернення*, *Статтю*, *Областю* та *Що цікавить на момент першого звернення*.
* **#14:** Кругова діаграма наявності запитів у клієнтів.
* **#15:** *Тривалість супроводу в днях* (`Дата закриття − Дата першого звернення`; записи без дати закриття не враховуються).
* **#16:** *Відсутність апдейту по клієнту в днях* (`|<Updated At> − Дата аналізу|`).

### 2. Вкладка «Запити» (17–25)
* **#17–18:** Запити по **Відповідальний КК** з розбивкою за *Етапом виконання запиту* та *Типом запиту*.
* **#19–22:** Розподіл запитів за колонками *РЕЗУЛЬТАТИ*, *Оцінка вирішення запиту*, *Загальна кількість консультацій* (з окремою категорією для пустих клітинок) та *Номер запиту*.
* **#23:** *Тривалість запиту в днях* (`Дата завершення запиту − Дата створення запиту`; без дати завершення не враховується).
* **#24:** *Відсутність апдейту по запиту в днях* (`|<Updated At> − Дата аналізу|`).
* **#25:** Кругова діаграма звірки ID клієнтів між вкладками *«Запити»* та *«Клієнти»*.

### 3. Вкладка «Послуги» (26–28)
* **#26:** Кругова діаграма за колонкою *Етап послуги*.
* **#27:** Стовпчаста діаграма за колонкою *Тип послуги*.
* **#28:** Кругова діаграма перехресної звірки ID клієнтів та ID запитів між вкладками *«Послуги»*, *«Запити»* та *«Клієнти»*.

## 🚀 Як запустити та використовувати

### Варіант 1. Локальний запуск на комп'ютері
1. Завантажте файл `analytics_dashboard.html` із цього репозиторію.
2. Відкрийте його подвійним кліком у будь-якому сучасному браузері (Chrome, Edge, Firefox, Safari).
3. Натисніть **«Завантажити Excel (.xlsx)»** (або перетягніть файл у вікно браузера) чи скористайтеся кнопкою **«Google Таблиця»**.

### Варіант 2. Публікація через GitHub Pages
1. Перейменуйте `analytics_dashboard.html` на `index.html` (або залиште поточну назву).
2. У репозиторії перейдіть у **Settings → Pages**.
3. У розділі **Build and deployment** оберіть гілку `main` та папку `/ (root)`, натисніть **Save**.
4. Через 1–2 хвилини дешборд буде доступний за постійним вебпосиланням для всієї команди.

## 📋 Вимоги до структури вхідних даних

Документ Excel або Google Таблиця повинен містити три аркуші з назвами:
* `Клієнти`
* `Запити`
* `Послуги`

> **Примітка для Google Таблиць:** для завантаження за посиланням у налаштуваннях доступу таблиці має бути ввімкнено режим **«Усі, хто має посилання» (Переглядач)**.

## 🛠 Технологічний стек

* **HTML5 / Vanilla JavaScript (ES6+)** — архітектура без необхідності збірки (Single-File Application).
* **Tailwind CSS** — адаптивний інтерфейс та підтримка світлої/темної теми.
* **D3.js (v7)** — побудова інтерактивних стовпчастих та кільцевих діаграм.
* **SheetJS (xlsx)** — клієнтський парсинг `.xlsx`, `.xls` та `.csv` файлів.
